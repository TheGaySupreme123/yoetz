# Sample reviews

Draft Product Hunt / social comments. Not real user quotes — copy you can post or adapt.

---

**1. Math / problem sets**

This is the first tool that matches how I actually use coding agents on math.

I don’t need another model. I need something that notices when the write-up says every case is covered and the boundary I asked for was never checked. Yoetz sits next to Codex and does that. It doesn’t pretend the proof is correct. It just won’t let “done” go unexamined.

Local, open source, and it stays out of the way until the agent tries to declare victory. That’s when I want it.

**2. Short PH hunter**

Rare launch that knows what it is not. Yoetz is not a coding agent. It checks whether yours actually did the thing it claimed. The stale-tests example sold me. Tried it on a real task and it caught a “tests pass” from before the last edit. Instant upvote.

**3. Research / messy agent work**

I use agents for long, boring, easy-to-half-finish work. They are fast. They are also confident.

Yoetz is the first thing I’ve seen that treats that confidence as a claim, not a vibe. Evidence in, check, findings back to the agent. Optional model review if you want it; the default stays on your machine.

If you have ever re-read an agent’s output because you didn’t quite trust the last paragraph, this is for you.

**4. Engineer, one paragraph**

I already have Cursor. I didn’t want a second agent. Yoetz hooked in, recorded what the agent said it did, and flagged a test run that was older than the diff. That’s the whole product, and it’s the part I was doing by hand. Open source, local-first, honest about not guaranteeing correctness. More of this, please.

**5. Super short**

Finally, something that argues with the agent so I don’t have to. Caught skipped steps on a problem set. Local-first. Upvoted.

**6. “Why this, not another wrapper”**

Most AI launches add a chat box. Yoetz adds a spine.

Your agent still writes the code or the proof. Yoetz keeps a ledger of what was promised, what was run, and what still isn’t supported — then hands findings back so the agent can fix them. Deterministic checks first. Semantic review only if you opt in.

The restraint is the feature. It will not tell you the work is correct. After a year of tools that overclaim, that feels like a relief.

**7. From a student who still checks the work**

I used to keep a mental list after every agent session: did it handle n = 0? did it follow the constraint in the prompt? did it even run what it said it ran?

Yoetz is that list, written down, so I can go back to the actual mathematics. It missed nothing theatrical. It caught the boring stuff — which is exactly what I was missing.

Try it on something you already know is slightly wrong. That’s the demo.
