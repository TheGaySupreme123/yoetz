## Purpose

Add forward-only task-bundle tables for live Codex observation consent, cursors, dedup, structural
events, and advice snapshots. Existing v0.1 ledger/object/import data remains readable without
rewrite.

## Public surface

- migration family `bundle`, version `0002`, previous version `0001`
- UTF-8/LF text, final LF, no BOM
- tables `observation_consent`, `observation_cursors`, `observation_dedup`, `observation_events`,
  `observation_advice`
- `PRAGMA user_version = 2`

## Behavior

Creates only observation tables and indexes. Does not alter migration `0001` tables. Sensitive
evidence remains in encrypted objects; plaintext columns hold commitments and allowlisted structure.

## Errors and edge cases

Invalid DDL bytes fail registry load. Applying against a non-1 user_version fails closed in the
migration runner.

## Invariants

1. Released `0001` bytes remain immutable.
2. Observation tables are `STRICT`; commitment-keyed tables use `WITHOUT ROWID` where appropriate.
3. No transcript prose columns exist.

## Tests

Migration registry continuity and bundle initialize/migrate unit coverage.
