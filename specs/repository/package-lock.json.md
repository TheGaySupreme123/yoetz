# package-lock.json — exact development-only Pyright dependency graph

**Wave:** F | **ADRs:** ADR-007 | **Imports (spec-tree):** `package.json.md` | **Imported by:**
`npm ci`, dependency/license audit, and PR type-check workflow

## Purpose

Make the development type checker and all npm-supplied transitive bytes reproducible and
reviewable.

## Public surface

An npm lockfile v3 generated by npm `12.0.1` under Node `26.5.0` from the reviewed `package.json`.
Its root identity, engines, and development dependency exactly mirror that private package; npm
lockfile v3 does not duplicate the `package.json` `private` flag. `pyright` is rooted at exactly
`1.1.411`, with exact package versions, integrity strings, resolved registry locations, licenses,
and engine constraints for the official dependency graph. That graph includes Pyright's exact
optional Darwin member `fsevents==2.3.3`; its lock metadata truthfully records
`hasInstallScript: true`, but the script is never executed because every install uses
`npm ci --ignore-scripts`.

## Behavior

The file is first generated with the 2026-07-17 implementation-lock toolchain and regenerated only
with the documented release-lock npm version after deliberately changing `package.json`. CI uses
Node `26.5.0`, npm `12.0.1`, and `npm ci --ignore-scripts`; it never runs `npm install` or mutates
the lock. The dependency audit compares every member and license against the reviewed allowlist.

## Errors and edge cases

Missing integrity, non-registry source, mutable URL, unexpected dependency, unsupported Node
engine, or clean-install diff blocks CI. A root lifecycle script or execution of any dependency
script is forbidden. The one lock-recorded optional `fsevents==2.3.3` install script is retained as
truthful upstream metadata and must remain unexecuted under `--ignore-scripts`; any other
install-script-bearing member requires an explicit dependency-lock amendment. A platform-specific
optional member is not treated as a Yoetz runtime dependency.

## Invariants

The lock resolves one development toolchain only; it is not included in the wheel, consulted at
runtime, or used as authority for Python dependency versions.
