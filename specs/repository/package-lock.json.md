# package-lock.json — exact development-only Pyright dependency graph

**Wave:** F | **ADRs:** ADR-007 | **Imports (spec-tree):** `package.json.md` | **Imported by:**
`npm ci`, dependency/license audit, and PR type-check workflow

## Purpose

Make the development type checker and all npm-supplied transitive bytes reproducible and
reviewable.

## Public surface

An npm lockfile v3 generated from the reviewed `package.json`, with the root package marked
private and exact package versions, integrity strings, resolved registry locations, licenses, and
engine constraints for the official Pyright dependency graph.

## Behavior

The file is regenerated only with the documented release-lock npm version after deliberately
changing `package.json`. CI uses `npm ci --ignore-scripts`; it never runs `npm install` or mutates
the lock. The dependency audit compares every member and license against the reviewed allowlist.

## Errors and edge cases

Missing integrity, non-registry source, mutable URL, install script, unexpected dependency,
unsupported Node engine, or clean-install diff blocks CI. A platform-specific optional member is
retained exactly as npm locks it and is not treated as a Yoetz runtime dependency.

## Invariants

The lock resolves one development toolchain only; it is not included in the wheel, consulted at
runtime, or used as authority for Python dependency versions.
