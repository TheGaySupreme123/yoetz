# .gitignore — public repository exclusion boundary

**Wave:** A/F | **ADRs:** ADR-007 | **Imports (spec-tree):** `specs/README.md`,
`scripts/scan_public_boundary.py.md` | **Imported by:** contributors, public-boundary CI, release
source inventory

## Purpose

Exclude local private drafting inputs and reproducible developer/build artifacts without hiding
public source, specifications, security-relevant configuration, migrations, fixtures, or release
inputs from review.

## Public surface

One LF-terminated Git ignore file with commented groups for: the entire local
`/docs/architecture/` drafting-input directory; Python/pytest/type-check caches; virtual
environments; build/distribution outputs; coverage reports; local environment/secret files;
OS/editor transient files; and project-local debug/temp evidence directories.

## Behavior

Patterns are repository-relative where the excluded name is project-specific and narrowly scoped
for generic caches. The private drafting-input rule is the directory rule
`/docs/architecture/`, not a list that leaks individual strategy document names. Public ADRs,
`specs/`, schemas, migrations, fixtures, skills, scripts, workflows, lockfiles, and example-safe
documentation are never ignored. CI compares tracked/candidate release inventory independently;
Git ignore is convenience, not a security or publication proof.

## Errors and edge cases

Broad rules such as `docs/`, `*.json`, `*.sql`, `*.md`, `tests/`, or `resources/` are forbidden.
Negation tricks, absolute home paths, credential values, private filenames, or machine-specific
directory names fail the public-boundary scan. A sensitive file already tracked is not protected by
adding a pattern and must be removed through explicit reviewed history handling.

## Invariants

1. Private architecture/strategy drafting inputs remain untracked as one directory class.
2. Every public contract/release input remains visible to Git and manifest validation.
3. Ignore rules contain no secret or private document inventory.
4. Publication safety is enforced by allowlisted artifact scans in addition to this file.
